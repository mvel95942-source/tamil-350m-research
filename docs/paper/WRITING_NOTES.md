# Writing notes: rules this draft follows

Ten rules, each with its source. Sources marked (read) were fetched and read on 2026-11-03. Sources marked (snippet) were only seen as a search summary; their full text was not read.

1. **Length.** Long paper = 8 pages of content in review mode (9 final), short = 4 (5 final). References are unlimited. Figures and tables count. Over-length means desk rejection. (read) [ACL formatting](https://acl-org.github.io/ACLPUB/formatting.html), [ARR CFP](https://aclrollingreview.org/cfp)
2. **Limitations section is mandatory**, titled "Limitations", after the conclusion and before References, outside the page limit. It may hold no new experiments, figures or analysis. No Limitations section = desk reject. (read) same two links.
3. **Ethical considerations** section is encouraged, same placement, same no-new-results rule. (read) same links.
4. **Responsible NLP checklist** is filled in the submission form (limitations, risks, artifact licences and intended use, data statistics, compute and parameter counts, hyperparameters, run counts, package versions, AI-assistant use). Wrong or missing answers can cause desk rejection. AI help with writing or code must be disclosed there and in Acknowledgements. (read) [Responsible NLP checklist](https://aclrollingreview.org/responsibleNLPresearch/), [ARR CFP](https://aclrollingreview.org/cfp)
5. **Anonymity.** No names or affiliations; no "we previously showed" self-citations (write "Smith showed"); anonymize linked repos and supplements; no Dropbox/Drive links. Review mode adds line numbers; the Acknowledgements section is dropped in review. (read) [ARR CFP](https://aclrollingreview.org/cfp), [ACL formatting](https://acl-org.github.io/ACLPUB/formatting.html)
6. **Use the official style.** `acl.sty`, `acl_natbib.bst`, templates `acl_latex.tex` (pdfLaTeX) and `acl_lualatex.tex` (LuaLaTeX/XeLaTeX) from [acl-org/acl-style-files](https://github.com/acl-org/acl-style-files). (read) This draft uses LuaLaTeX/XeLaTeX because pdfLaTeX cannot typeset Tamil.
7. **References.** Unnumbered "References" heading, alphabetical, full author names, DOI or ACL Anthology link where one exists. (read) [ACL formatting](https://acl-org.github.io/ACLPUB/formatting.html)
8. **Limitations content.** Name strong assumptions and how robust the results are if they fail; state the scope of the claims (languages, datasets, runs). Candour is not penalized. (read) [Responsible NLP checklist](https://aclrollingreview.org/responsibleNLPresearch/)
9. **Intro answers "why" before "how"; abstract is a summary of the intro and is written last; one sentence per abstract component.** (snippet) [Vered Shwartz, Tips for Writing NLP Papers](https://medium.com/@vered1986/tips-for-writing-nlp-papers-9c729a2f9e1f) (the page returned HTTP 403 on fetch; only the search summary was seen).
10. **Claims-evidence discipline** (my own rule, applied throughout): every contribution bullet points to a table, figure or section; a result that is not measured is a red `PENDING` cell, never an estimate. The cited Simon Peyton Jones talk ([page](https://www.microsoft.com/en-us/research/academic-program/write-great-research-paper/)) recommends listing contributions with their evidence, but its slides could not be read here (PDF returned no text), so treat that as unverified.

Not read: Graham Neubig's writing tutorial and the Stanford CS224u handout (appeared in search results only).
